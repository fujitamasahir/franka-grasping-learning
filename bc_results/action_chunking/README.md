# Action Chunking

Action chunking. `action_chunking_protocol.json` and its SHA record the frozen design; `action_chunking_eval/` contains paired BC/SAC rollouts, `action_chunking_bc_runs/` and `action_chunking_sac/` contain training histories/configs, `action_chunking_analysis/` has derived tables, and `action_chunking_figures/` has plots. The report is in `experiments/residual-sac/EXPERIMENTS_ACTION_CHUNKED_BC_RESIDUAL_RL.md`.
